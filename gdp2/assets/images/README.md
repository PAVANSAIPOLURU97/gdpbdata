# Images go here

Drop your files in this folder using these exact names (or update the matching
path in `assets/js/config.js` if you want to use different names):

| File name | Used for |
|---|---|
| logo.png | App logo — shown on login page and top bar |
| icon-master.png | Master tab tile icon |
| icon-milk-input.png | Milk Input tab tile icon |
| icon-procurement.png | Raw Material Procurement tab tile icon |
| icon-products-made.png | Products Made tab tile icon |
| icon-sales.png | Sales tab tile icon |
| icon-dashboards.png | Dashboards tab tile icon |
| icon-user.png | Small "User ID" field icon on login page |
| icon-lock.png | Small "Password" field icon on login page |
| icon-logout.png | Logout button icon |
| icon-units.png | Units sub-tab tile icon |
| icon-milk-master.png | Milk Master sub-tab tile icon |
| icon-rawmaterials.png | Raw Materials sub-tab tile icon |
| icon-product-master.png | Product Master sub-tab tile icon |
| icon-employee-master.png | Employee Master sub-tab tile icon |

Until a file is added, the app quietly hides that image instead of showing a
broken-image icon — so it's safe to add these one at a time.

Recommended size: square PNGs, at least 256x256px, transparent background.
